# HackAlem AI — Agentic AI прогноз выработки ВЭС (KnewIT 3)

Хакатонный проект: агентная система почасового прогноза выработки двух ветротурбин
(Шелек, Алматинская обл.) на 24–48 часов по архивным прогнозам погоды.
Тестовый период — февраль 2026, судьи сверяют с фактом. **Дедлайн: сегодня 18:00.**

## Прежде чем писать код

1. Прочитай `docs/CASE.md` (ТЗ) и свою зону в `docs/TASKS.md`. Работай **только в своих модулях**
   (таблица ролей там же). Чужой модуль не менять — параллельно работают три человека.
2. Контракты функций между модулями — в `docs/ARCHITECTURE.md`. Реализуй ровно эти сигнатуры.
   Менять контракт можно только после согласования всей командой.
3. Решения и их причины — `docs/DECISIONS.md`. Не пересматривай их молча.

## Правила, которые нельзя нарушать

1. **Никакой фактической погоды на входе инференса.** Только архивные прогнозы
   (previous-runs-api). ERA5/реанализ/фактические измерения в фичах инференса = нарушение ТЗ.
2. **Никакой утечки будущего.** Split только по времени; holdout 12.2025–01.2026 не участвует
   в обучении и подборе, кроме финального замера и весов бленда.
3. **Время — Asia/Almaty везде.** Каждый запрос к Open-Meteo с `timezone=Asia/Almaty`.
4. **Все ответы погодных API кэшируются** в `data/weather_cache/` и коммитятся. Повторный
   запуск должен работать офлайн.
5. **Прогноз клипается в [0, 1]** — мощность нормализована.
6. **`ANTHROPIC_API_KEY` только из `.env`**, `.env` в `.gitignore`. Всё должно запускаться
   и с `--no-llm` без ключей.
7. **Коммит минимум раз в час** с рабочим состоянием (правило хакатона 5.4.8–5.4.11).
   Работа в короткоживущих ветках `dev/weather|models|agent` (см. `docs/GIT_WORKFLOW.md`),
   merge в `main` не реже раза в час. Версия на 18:00 — финальная.
7а. **Никаких трейлеров про ИИ в коммитах** (`Co-Authored-By: Claude` и подобных) —
   ни в новых сообщениях, ни в PR.
8. Отметку `[x]` в `docs/TASKS.md` ставить тем же коммитом, что и задачу.

## Стек

Python 3.11+ · venv+pip · pandas · LightGBM · scikit-learn · httpx · anthropic.
GPU не используется. Комментарии и коммиты — на русском, имена в коде — английские.

## Контекст, о котором легко забыть

- Судьи ставят 25 баллов за README и воспроизводимость: любой новый шаг запуска — сразу в README.
- Датасет 10-минутный, прогноз почасовой: агрегация по правилам `docs/DATA.md` (≥4/6 интервалов,
  простои выкидываем из обучения).
- У турбины 1 дыра в данных ~41 день — код обязан переживать разрывы ряда.
- Турбины в 300 м: погода одна на двоих, модели — раздельные.
- Прогноз «на день D, сделанный в D-1» = `_previous_day1` для часов D и `_previous_day2`
  для часов D+1 (проверить на живом ответе!).
