# Официальное ТЗ: Agentic AI для прогнозирования выработки ВЭС

Источник: «HackAlem AI: Agentic AI для прогнозирования выработки ВЭС.docx», получено 23.09.2026.
Это исходный документ кейса — **не редактировать**, только сверяться.

## Описание задачи

Разработать Agentic AI-систему для прогнозирования **почасовой** выработки ветроэлектростанции (ВЭС)
на горизонте **24–48 часов**.

Даны координаты и исторические данные работы ВЭС с марта 2023 до 31 января 2026 включительно.
Прогнозирование выполняется за тестовый период **с 1 по 28 февраля 2026**.

## Предоставляемые данные

- Координаты турбины 1: 43.645150, 78.535604 ([ссылка](https://maps.app.goo.gl/iN6svMt69D5qRpFU9))
- Координаты турбины 2: 43.643198, 78.538828 ([ссылка](https://maps.app.goo.gl/8UQMwsYavY6nLvFY8))
- Статистическое время (10-минутные интервалы)
- Средняя скорость ветра, м/с
- Нормализованная активная мощность на стороне линии (0–1)
- Средняя температура окружающей среды, °C

## Задача участников

Решение должно:

1. На исторических данных построить модель прогнозирования почасовой выработки.
2. **Самостоятельно** получать по координатам ВЭС погодные прогнозы из открытых источников,
   **доступные на соответствующий момент прогнозирования**.
3. Формировать прогноз выработки на следующие 24–48 часов с почасовой детализацией.
4. Реализовать процесс в формате Agentic AI — система сама выполняет полный цикл:
   получение внешних погодных данных → подготовка данных → запуск модели →
   формирование почасового прогноза → анализ результата → повторный расчёт при обновлении входных данных.

Выбор источников погоды, ML-моделей, методов обработки и архитектуры агента — за участниками.

## Протокол воспроизведения (rolling-прогноз)

Воспроизвести процесс, как если бы прогноз выполнялся в прошлом:

- на 31 января — прогноз на следующие 24–48 часов;
- на 1 февраля — новый прогноз на следующие 24–48 часов;
- далее последовательно по всему тестовому периоду.

**Критично:** для каждого прогнозного периода использовать **архивные прогнозы погоды**,
доступные на момент прогнозирования, а не фактические значения, ставшие известными позднее.
