## Приёмка общей версии

| Владелец | Задача | Состояние |
| --- | --- | --- |
| Интегратор | Округление общего стека признаков до 10 знаков, пересборка финальных и оценочных моделей, CSV, отчётов и manifest | Готово; канонические отчёты `--no-llm` |
| Интегратор | Полные тесты общей версии, повторение 28 выпусков / 1344 turbine-hours на macOS и Linux без сети, допуск `1e-9`, запуск панели | Проверено: 145 тестов на каждой платформе, оба режима панели, lead 2 и обновление без ошибок JavaScript |
| Интегратор | Согласовать README и документацию с пересобранными артефактами, опубликовать общую версию | Документация согласована; публикация общей версии — после завершения слияния |

Новые 28 канонических отчётов сформированы с `--no-llm`, поскольку в среде пересборки нет
API-ключа. Старые LLM-объяснения не переносятся на новые прогнозы; прежний комплект
доступен в git-истории. Строгая репетиция заняла 7.3 с на macOS и 11.4 с на Linux
aarch64 glibc; совпали 1344/1344 строки подачи и 5904/5904 строки оценки.
Максимальные отклонения — 0 и `1.11e-16`. Команды и результаты —
[INTEGRATION](INTEGRATION.md).
