## Ограничения

Декабрь–январь уже влияли на решения команды: оценка ретроспективная, а не нетронутый
тест. Февральского факта нет. Previous Runs не хранит доказательство точного времени
публикации каждого значения; см. FEATURE_AVAILABILITY. Наличие Dockerfile само по себе
не доказывает прохождение контейнерного запуска. LLM-проверка требует действующего ключа.
